# Workspace preferences

## Browser
- Always use **Brave** for any browser automation, previews, or screenshots. **Never use or install Google Chrome.**
- Brave executable path (macOS): `/Applications/Brave Browser.app/Contents/MacOS/Brave Browser`
- When a tool defaults to Chrome, point it at Brave's executablePath instead, or launch Brave directly via its binary. Do not run `playwright install chrome`.

## Theme
- The app UI is a **light "paper white" theme**. Do not default to dark mode. Keep surfaces warm off-white, text near-black, with the established accent used sparingly.
