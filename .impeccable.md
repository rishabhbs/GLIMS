# Impeccable — Project Design Context

## Design Context

### Users
Internal users at Sampleify (a LIMS product company): a product marketer / PM, and the team.
They use the tool in focused desk sessions — asking the Brain grounded questions, curating
knowledge, and generating LinkedIn/social content from that knowledge. It's a working
instrument, not a consumer-facing app or a marketing site.

### Brand Personality
Precise, trustworthy, quietly editorial. Three words: **meticulous, grounded, considered.**
The product's whole premise is provenance — every claim is traceable — so the UI should feel
accountable and exact, like a well-kept lab notebook or a research tool, never flashy or
"AI-dashboard" generic.

### Aesthetic Direction
Dark theme (long focused work sessions, data-dense reading). Editorial-scientific: a warm
serif for headings paired with a clean humanist grotesque for UI/body. Restrained palette —
tinted slate neutrals toward a cool brand hue with a single warm accent used sparingly.
No neon-on-dark, no purple→blue gradients, no gradient text, no glassmorphism, no colored
side-stripe cards. Think Linear/Things precision crossed with a journal's typographic care.

### Design Principles
1. **Provenance is visible.** Grounding, citations, and status are first-class, legible, and calm — not buried, not shouting.
2. **Typographic hierarchy over boxes.** Lean on type scale, weight, and spacing rhythm; don't wrap everything in cards.
3. **One accent, used rarely.** 60/30/10 — tinted neutral surfaces, muted secondary, a single accent for the one action that matters.
4. **Quiet motion.** A single orchestrated entrance; feedback on state changes; respect prefers-reduced-motion.
5. **Dense but breathable.** Comfortable reading measure (~70ch), varied spacing, never cramped.
